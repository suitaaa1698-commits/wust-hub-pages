# 首页 Demo 的产品边界

这是武科大资源汇总站的独立首页设计预览，位于 `web/demo/`，不是已批准替换正式站点的全站设计系统。父目录之外的“智汇计科”产品文档不适用于此项目。

用户是武汉科技大学学生，希望集中查看竞赛、学校政策、历年记录与通知群。用户已经明确由开发者完成实现，用户通过实际效果审核；不需要教学练习或新增方向选择流程。

本次明确要求：模仿武汉科技大学创新创业学院官网 https://cxcy.wust.edu.cn/ 的 UI，微调内容，先写方案并做一版 Demo 首页。此指定参考优先于自由视觉创作。

必须保留：现有五个功能模块和真实来源信息；学生共建、非官方身份；数据加载失败时的可理解状态；手机和电脑访问。Demo 只修改自身目录与相关方案、验收文件，不替换现有首页，不变更后端、数据库、采集管线或公开部署。

数据事实：赛事与事件读取现有静态数据；政策和群来自已维护的 resources-data.js；校内通知是 2026-09-22 整理自学院官网及原文页的固定快照。展示的日期是发布日期，不是报名截止日。时间记录包含待核实的采集条目；历史按实际起始年份归档。群号按对应赛事届次查阅，不暗示仍开放报名。

预览的校园图片、纹理和大学标识取自指定学院官网，来源列于 assets/sources.json。未使用学院官方联系人、二维码或版权身份。
